# Code of Conduct

This project adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) by reference. It applies to every project space: the repository, issues, pull requests, discussions, and any other channel the project uses, as well as to public spaces when a person represents the project.

## Summary

Participants are expected to be respectful, to accept constructive feedback, and to focus on what is best for the project and its users. Harassment, personal attacks, publishing others' private information, and other behaviour that a reasonable person would consider inappropriate in a professional setting are not tolerated. The full text linked above lists the standards and the enforcement guidelines that apply.

## Reporting

Reports of unacceptable behaviour can be made to the project maintainers at the contact address published in this section: [synit.io](https://www.synit.io/kontakt). Until it is, use GitHub's [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) mechanism for behaviour on GitHub.

All reports are reviewed and investigated promptly and fairly, and the privacy of the reporter is respected.

## Enforcement

Maintainers follow the enforcement guidelines of the Contributor Covenant 2.1 (correction, warning, temporary ban, permanent ban) and are responsible for clarifying and enforcing these standards.
